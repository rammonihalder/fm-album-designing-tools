# Quick Correction Phase 1: Photoshop host check

This is a development-only UXP script, separate from the plugin panel. It changes only the selected pixel layer of an active, single-layer `.psb` document. It never saves, closes, flattens, rasterizes, or switches documents. Photoshop 23.5 or later is needed to run `.psjs` scripts.

## Command assessment

| Requested correction | Photoshop command being probed | Current support assessment |
| --- | --- | --- |
| Auto Color | Photoshop **Auto Color** | Native Photoshop feature. No Auto Color method was found in the documented UXP Document DOM. `_obj: "autoColor"` is a **candidate** batchPlay event name, not yet verified in this Photoshop host. |
| Auto White Balance | None | No universal native UXP Auto White Balance command or descriptor was established. Camera Raw has an Auto white-balance control, but its workflow and PSB applicability need separate research and host testing. The PoC reports `unsupported` and makes no change. |
| Auto Light | Photoshop **Auto Tone**, as a candidate only | Photoshop documents Auto Tone, Auto Contrast, and Auto Color, but does not identify a command named Auto Light. `_obj: "autoTone"` is a **candidate** event name. Whether Auto Tone meets the desired Auto Light behavior is a product decision after visual testing. |

The two event names above should be compared with the action descriptors generated by Photoshop itself: enable Developer Mode, record the matching Image menu command, then use Actions panel **Copy As JavaScript** or **Plugins > Development > Record Action Commands**. If Photoshop records a different descriptor, replace only the candidate descriptor in this script and repeat the host test. Do not infer Auto White Balance from Auto Color or Auto Tone.

## Run each check independently

1. In Photoshop, use a disposable photo in a manually opened embedded Smart Object `.psb`. Use a PSB with exactly one pixel or Background layer and select that layer. Keep the album PSD inactive. Do not test on an original JPG or PNG. For Auto Color, a photo with a noticeable color cast helps reveal an effect; for Auto Light, use a photo with poor tonal balance.
2. Open [quick-correction-poc.psjs](quick-correction-poc.psjs). Set `SELECTED_CORRECTION` to exactly one of `"autoColor"`, `"autoWhiteBalance"`, or `"autoLight"` and save the script file.
3. In Photoshop select **File > Scripts > Browse**, then choose the `.psjs` file. Alternatively use UXP Developer Tool **Debug Script**. No plugin panel button is involved.
4. Read the alert and, for the full structured result, the UXP Developer Tool console. Record `targetDocument`, `command`, `commandAccepted`, `historyStateAdded`, `modifiedIntendedDocument`, `visibleEffect`, `status`, and `error`.
5. Compare the active PSB to its appearance before the run and check the History panel. Record the visible effect as **yes / no / uncertain** yourself; the script deliberately reports `manual-check-required`. A new history state is evidence of a document mutation, but does not prove a visible pixel change.
6. Restore the test photo to its starting state manually (Undo or reopen a disposable PSB without saving). Repeat steps 2–5 for each correction. Do not save or close a user-opened PSB unless you choose to do so yourself.

Suggested record for each run:

| Correction | Photoshop version | PSB name and ID | Accepted? | New history state? | Intended PSB changed? | Visible effect? | Error text |
| --- | --- | --- | --- | --- | --- | --- | --- |
| Auto Color | | | | | | | |
| Auto White Balance | | | | | | | |
| Auto Light / Auto Tone candidate | | | | | | | |

`accepted-needs-visual-check` means batchPlay returned without a recognized error, **not** that the correction works or is visibly useful. A `failed`, `blocked`, or `unsupported` result is not success. If history information is unavailable or unchanged, intended-document modification remains unconfirmed.

## Still unverified in Photoshop

- Whether this Photoshop build accepts `_obj: "autoColor"` and `_obj: "autoTone"` for the active single-layer PSB.
- Whether either candidate creates a History state and visibly changes the intended photo.
- Whether Auto Tone's effect should be called **Auto Light** in the final product.
- Whether a distinct Auto White Balance workflow can be exposed through Camera Raw or another explicitly identified native command for embedded PSBs.
- Whether the script's PSB/layer eligibility checks match every embedded Smart Object generated by the album tools.
